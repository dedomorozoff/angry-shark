# Голодная Акула

Browser game where you control a hungry shark, eat fish, avoid enemies, and grow bigger.

## Play

Open `index.html` in any browser. No server needed.

- **Desktop**: move mouse to steer, edge-scroll to pan camera
- **Mobile**: virtual joystick appears automatically

## Features

- Procedural ocean world with corals, algae, rocks, light rays
- Prey fish, dangerous enemies (octopus, whale, bombs)
- AI rival sharks that also hunt and grow
- Start screen with animated intro
- Mini-map in corner
- Best score saved in localStorage
